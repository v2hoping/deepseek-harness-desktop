# DeepSeek Harness 桌面账户

[English](README.md) | 中文

在设置中增加账户页：把 DeepSeek API Key 放进模型凭据，并指向平台的充值页面。

## 为什么放在这里

这个页面需要 Electron 外壳：DeepSeek 平台没有公开的账户 API，其登录页拒绝被内嵌，其 Key 列表只返回脱敏值，因此可用的 Key 只存在于用户在官方页面执行创建后的那一次响应里。插件因此随桌面应用交付而不进入包层，由 `dsh plugin --profile web add` 作为外部插件装入 profile。上游包层没有任何改动。

## 页面做什么

账户页报告 DeepSeek provider 的凭据引用是否已存有 Key，并提供两条填入路径。**获取 API Key** 在携带平台会话的窗口中打开官方 Key 页；用户在那里创建 Key 后，外壳读取该页面自己的响应并存入。**粘贴 Key** 接受用户已有的 Key。两条路径都先用公开的 `GET /user/balance` 校验，再写入，因此存进去的 Key 是平台接受过的。页面同时链接到平台的充值、用量、账单与 Key 管理页面。

`credentials.describe` 永不返回值，因此已存的 Key 无法在此重新校验。页面保证的是：它写入的 Key 事先通过了校验。

## 页面不做什么

外壳从不以用户身份认证。它不提取会话 token、不代表用户向平台网站发送请求、不向任何官方页面注入脚本。每一个平台请求都来自平台自己的页面、带着它自己的设备标识；外壳通过 Electron 的 DevTools Protocol 只观察一个响应，不读取其它内容。本应用发出的唯一请求是公开的余额探测，由用户自己的 API Key 认证。

## 浏览器行为

浏览器半会检查桌面账户桥，缺失时不注册任何东西。因此普通的 `dsh web` 标签页看到的设置页面与此前完全一致。

## 模型体验

该插件不新增模型可见输入。存入 Key 改变的是 DeepSeek provider 解析到的凭据，这由既有的凭据子系统持有。
